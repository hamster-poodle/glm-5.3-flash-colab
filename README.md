# GLM-5.3-Flash on Google Colab

Strata-GLMでGLM-5.3-Flashを動かし、Colab内でチャットするためのノートブックです。**A100 80GB・RAM約167GiBで動作確認済み。** 修正コードとチャットUIを内蔵しています。

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/hamster-poodle/glm-5.3-flash-colab/blob/main/GLM_5_3_Flash_Strata_Colab_v3.ipynb)

## 使い方

1. 上の **Open in Colab** を押す。
2. 自分のGoogleアカウントで、ランタイムを **A100 GPU・高RAM** に設定する。
3. **「チャットを起動」左側の▶ボタンを1回**押す。
4. 準備完了後、そのセルに表示されるチャットで会話する。

起動済みのGLMは再利用します。新規ランタイムでは必要な準備を自動で進めます。初回にColabの実行確認が出た場合は内容を確認して許可してください。画面は短い案内と起動ボタンだけの2セル構成。コードは隠し、起動が終わると進捗をチャットに置き換えます。詳しい仕様や診断情報は [COLAB.md](COLAB.md) にまとめています。

**必要条件：A100 80GB、RAM 150GiB以上、モデル146.05GiB＋作業用10GiB以上の空きディスク。** A100 40GBやT4向けの設定ではありません。ColabのGPU割当は保証されません。

**Googleアカウントだけで誰でも実行できる構成ではありません。** 実行するアカウント自身でA100を選択できるColabの利用枠が必要です。A100がグレーアウトしている場合は、モデル取得を始めず、契約・利用枠・組織のライセンス割当を確認してください。別アカウントの契約が自動で共有されることは前提にしていません。

モデル取得は約7〜8分、起動は約6〜9分を観測しました。初回はビルドも必要です。検証時の表示消費率は約6.77 CU/時。自分の利用枠・残りCUを確認してください。

詳細は **[実行手順・環境・トラブル対応（COLAB.md）](COLAB.md)** を参照してください。

## 推奨プラン・申込先

**個人でこれから始めるなら、今回の動作確認に使ったGoogle AI Proを第一候補にしてください。** 公式ヘルプではColabの200 CCUが案内されています。すでにA100を利用できるColab契約がある場合は、その契約を使えます。

- **個人向け： [Google AI Proのプラン・申込み](https://one.google.com/about/google-ai-plans/)** — 料金・Colab特典は購入するアカウントの画面で確認してください。
- **Colab中心の利用： [Colab有料プラン](https://colab.research.google.com/signup)** — Colab Pro / Pro+等の提供状況を確認できます。会社・学校のアカウントは、管理者によるColab有効化・ライセンス割当も確認してください。

Google AI Proの**無料体験にはColab特典が含まれません**。ストレージのみのGoogle One契約や、家族から共有された特典だけで利用できるとも限りません。実行するアカウント本人の適用条件を確認してください。高額なUltraへの加入を、このノートブックの必須条件にはしていません。

**有料プランでもA100 80GBの割当は保証されません。** 加入後は同じアカウントでColabのCU残高・A100選択可否を確認してください。起動ボタンを押すと実際のGPUとRAMを自動確認し、対象外なら案内して停止します。

公式情報（2026-10-12確認）：[Google AI ProのColab特典・対象条件](https://support.google.com/googleone/answer/14534406?hl=en)、[Colab FAQ](https://research.google.com/colaboratory/faq.html)。

## 使える機能

| 機能 | 使い方 |
|---|---|
| 画像の理解・文字の読み取り | 「画像・文書・URL」で画像を選択すると自動添付→質問を送信 |
| 画像URL・Webページ・PDF URL | URLを入力して「URLを読み込む」→出典・読取範囲を確認して質問 |
| PDF | 先頭20ページまで文字抽出。文字を抽出できないPDFは先頭2ページを画像として読取 |
| TXT / Markdown / CSV / JSON / コード / DOCX | ファイルを添付して要約・比較・質問。DOCXは本文と表の文字のみ |
| 会話の保存・復元 | JSONで画像を含む履歴を保存・復元、Markdownで文章を保存 |
| 質問の編集 | 「直前の質問を編集」で最後の質問と添付を戻して再送信 |
| 生成設定 | 温度・システム指示・最大出力を調整 |

画像機能はGLM本体のマルチモーダル経路を使います。固定版llama.cpp（b11461）でCPU画像エンコーダーをビルドし、同じモデル配布元から `mmproj-F16.gguf` を追加取得します。初回は追加のビルド・ダウンロード時間が必要です。旧テキスト版が起動中なら、起動セルで必要な準備後にサーバーを再起動します。

実機で図形識別、画像の文字 `MANGO 73` の転記、公開Webページの取得と質問、画像を含む履歴JSONの復元処理を確認しました。実測と検証範囲は [COLAB.md](COLAB.md) に記載しています。

ブラウザE2Eでも、実ファイル添付・画像とスキャンPDFへの質問・会話の継続・URL読取・JSONのダウンロードと再アップロードによる復元を確認済みです。画面はColab標準HTML/kernel callback方式で、ファイル選択後は自動添付、Ctrl/⌘+Enterで送信できます。回答は生成完了後に表示し、待機中は経過秒数を表示します。検証中にエンジンの空回答を再起動で復旧した事象があり、長時間安定性は未確認です。

**上限：** 1ファイル10MiB、1送信の画像2枚・資料本文16000文字程度、画像は最大2048px。切り詰めた範囲は画面に表示します。会話全体は32Kコンテキスト内で利用してください。長くなったら履歴を保存して「新しい会話」に切り替えます。

URLはColabから明示的に取得します。ログインページ・JavaScript描画・Web検索・音声・動画には未対応です。スキャンPDFの全ページOCRや表構造の完全な復元を保証するものではありません。JSON履歴には添付画像・資料本文も含まれるので、公開前に内容を確認してください。

## 動作確認の結果

| 項目 | 実測・設定 |
|---|---|
| モデル | 通常版 `unsloth/GLM-5.3-Flash-GGUF` / `UD-IQ4_XS` |
| 検証環境 | A100-SXM4-80GB / RAM167.1GiB / CUDA13.0 |
| GPUエキスパートキャッシュ | 66.36GiB |
| RAM常駐 | 67.46GiB（page-locked） |
| 生成速度 | 12.0 tok/s |
| 最初の出力 / 全体 | 7.33秒 / 34.45秒 |
| 入力 / 出力 | 61 / 328トークン、入力キャッシュ0、stop終了 |

2026-10-12の単発測定です。質問・回答長・割当で速度は変わります。RAM検出修正前は5.3 tok/sでした。expert skippingはオフ、コンテキスト設定は32Kです。

ビルド、RAM常駐、再起動、チャットの複数ターンを確認しました。共有版のコード検証と、固定ソースへの修正適用・再適用も確認しています。**第三者アカウントの新規ランタイムでの全工程実行、別GPU、32K最大長の負荷試験は未検証です。**

別アカウントでの確認（2026-10-12）：公開GitHub経由で18セルの読み込みに成功しました。そのアカウントではA100を選択できず、セットアップ・推論の検証には進めませんでした。したがって、リンク共有の確認と、新規環境での実行成功は区別しています。

配布経路の確認：GitHubの4ファイルを未認証で取得でき、配布元ファイルと一致しました。固定revisionのエンジン主要ファイル、およびモデル5分割すべての取得URLも未認証で応答200を確認しました。受け取った人に作者のDrive権限・GitHub認証・Hugging Faceトークンは不要です。Colabの実行には本人のGoogleログインと対応する利用枠が必要です。

## 保存と終了

初心者向け表示は全2セルです。稼働中サーバーの再利用・RAM常駐確認・チャット表示を実機確認しました。新規環境の一括起動経路は、内蔵処理の構文・処理順を確認していますが、新規ランタイムでの全工程再実行は未実施です。

モデルはColabの一時ディスクへ取得します。Driveへのモデル退避は行いません。必要な回答は保存し、終了時は **「ランタイム → 接続解除してランタイムを削除」** で利用を終了してください。モデルも消えるため、新規ランタイムでは再取得します。

APIはColab内のループバック接続のみ。公開トンネルや外部の有料推論APIは使いません。ColabはGoogleのクラウドなので、ローカルPC内だけで完結する構成ではありません。
